# JWRI HUST-UOsaka

Public website: https://jwri-hust.github.io/

Contact: duy.hanle@hust.edu.vn

Static HTML site. Shared appearance: site.css. Four-language interface: site.js. Article pages preserve the Vietnamese source content and source bilingual equipment tables. No admin data, credentials, or database dumps are published.

Content imported from public pages at https://jwri-hust.com/ on 2026-10-31. Inventory: migration-inventory.json.

Booking opens an email draft; requests are confirmed by staff. It does not make or confirm a reservation automatically.

Fonts are hosted locally with Vietnamese glyph coverage; see FONT-LICENSE.txt. Text files use UTF-8 and Unicode NFC.

Edit the HTML files to update articles. Keep media files local. GitHub Pages publishes the main branch root.
